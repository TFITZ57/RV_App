# Definition of Done (MVP)

- [ ] Start/advance/finish session flows work via API and minimal UI.
- [ ] Targets packaged with SHA‑256; Tasker produces HMAC Target IDs.
- [ ] Monitor enforces non‑leading prompts and triggers AOL breaks on object nouns.
- [ ] Transcripts persist; judging pool built; rank‑order returns average rank + effect size.
- [ ] Feedback reveals target after judging.
- [ ] Repo runs with `pip install -r requirements.txt` and `uvicorn backend.app:app --reload`.
- [ ] Basic tests pass (scoring, guardrails, HMAC determinism).
